# Open Research

An open-source research tool that redefines the research workflow, built before Anthropic's official product definition. Inspired by Claude Science but with significant improvements and innovations.

## Features

- **Advanced Paper Search**: Enhanced academic paper discovery and search capabilities
- **Real-time Collaboration**: Multi-user real-time collaboration for research teams
- **AI-powered Analysis**: Intelligent AI-assisted research analysis and insights
- **Data Integration**: Seamless integration of multiple research data sources
- **Knowledge Graph**: Visual knowledge graph for connecting research concepts
- **Citation Management**: Comprehensive citation tracking and management
- **Research Notes**: Organized note-taking system for research findings

## Tech Stack

- **Language**: TypeScript (Full-stack)
- **Frontend**: Open Designer
- **Deployment**: Local

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
